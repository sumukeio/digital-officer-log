# [阶段规格] spec_tools_integration.md — 智能工牌制作与转班提醒小助手全栈融合

> **阶段标识**：`phase-tools-integration-20260901`  
> **所属版本**：v0.3.0  
> **责任体系**：数字官工作台扩展工具集 (Next.js 16 + React 19 + TypeScript 5)  
> **状态**：[权威/现行]

---

## 一、阶段背景与目标 (Goals)

将原有独立的两个 Python 工具全面重构为 Next.js 纯全栈应用模块，无缝嵌入数字官工作台：
1. **智能工牌制作工作台 (`/badge`)**：
   - 替代原 Python Tkinter + ReportLab，实现前端 1:1 所见即所得 (WYSIWYG) 工牌排版与实时渲染；
   - 支持 Excel 批量导入、模板下载、手动快速录入，以及一键从工作台系统用户列表读取数据；
   - 前端合成公司 Logo、姓名、部门、岗位、工号、入职日期、照片框及员工专属矢量二维码；
   - 采用标准 CSS `@page` 与精准 A4 拼版网格（带裁切线），实现零失真高清晰度浏览器原生矢量打印与 PDF 导出。
2. **转班提醒与排班小助手 (`/shifts`)**：
   - 替代原 Python 脚本 + JSON 读写，排班数据升级为数据库持久化存储；
   - 完整移植白夜班自动翻转、自愈推算算法，保证日期过期自动向前推算修正；
   - 具备清晰的排班看板（今天转班/明天转班/全员倒计时追踪），提供企微 Markdown 消息实时预览与一键推送；
   - 接入工作台内置 `node-cron` 定时引擎（`src/lib/cron.ts`），每日 08:00 准时自动扫描与企微群预警。

---

## 二、非目标 (Non-goals)

1. 不修改原有日报、周报及权限核心业务逻辑；
2. 不引入庞大的 Python 运行时依赖或外挂微服务，完全以 Next.js / TypeScript 原生能力交付；
3. 不破坏既有单元测试与自动化验证体系。

---

## 三、验收标准 (Acceptance Criteria)

1. **工牌模块 (`/badge`)**：
   - Excel 导入支持 `.xlsx` 格式并正确解析字段；
   - 支持实时工牌预览与动态参数配置；
   - A4 拼版网格（2x4 / 2x5）准确渲染裁切线，支持调起浏览器打印。
2. **转班助手模块 (`/shifts`)**：
   - 员工排班增删改查正常，支持调班与周期设置；
   - 自愈推算与明天转班判定算法 100% 通过 Jest 单元测试；
   - 企微 Webhook 测试推送与定时推送正常工作。
3. **系统集成与质量**：
   - 工作台顶部导航与移动端菜单包含两处快捷入口；
   - `npm test` 全量单测通过；
   - `npm run build` 生产构建成功，无类型与 Lint 错误。
