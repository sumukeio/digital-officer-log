## 1. 业务目标与愿景 (Goals)

在数字官工作台中构建**「海铭德系统使用情况自动总结周报」**（Weekly Report Auto Summarizer）工作台，彻底取代人工逐个查表、手动计算指标、手写模板格式的繁琐流程。

### 核心目标 (Goals)
1. **多模块 Excel 批量拖拽导入与防重复校验**：支持一次性拖入海铭德系统导出的多个 `.xlsx` 表格，进行文件级去重判断。
2. **基于“前缀+表头特征”的智能识别引擎**：
   - **生产头条**（文件名以“生产头条”开头，表头含 `卡号`、`标题`、`优先级`）：自动提取停机时长、车间名称、责任人；计算开卡总数、超 24h/48h 停机数量与明细、7 大智造车间（一部/二部/三部/五部/七部/八部/九部等）分布与占比（未开卡车间补 0%）、与上周开卡环比。
   - **QC头条**（文件名仍以“生产头条”开头，表头含 `行号`、`设备编号`、`问题`）：自动提取处理时长、负责人；计算开卡总数、超 24h/48h 处理数量及负责人、与上周开卡环比。
   - **OKR**（文件名以“OKR”开头）：计算开卡总数与环比。
   - **新随拍**（文件名以“打卡记录”开头，表头含 `打卡人`、`部门`、`打卡区域`、`打卡时间`）：统计打卡总人次、各部门打卡占比（内置“一组/一部”、“五组/五部”智能归一，同时自适应抓取提取所有真实出现的部门）、与上周环比。
   - **综合点检 / 精益（可选）**：支持文件解析与按车间统计，周报模块支持勾选启用/禁用。
3. **周期自动判定与快捷选择**：
   - 默认根据当前系统日期自动推导当周（周一至周日）起止日期（如 `8.24-8.30`）及周数；
   - 页面顶部提供快捷选择器（本周/上周/自定义日期范围），支持灵活切换。
4. **数据沉淀与历史自动环比**：
   - 数据库中持久化存储每次保存的周报与关键指标快照；
   - 支持先上传上周数据入库，当周周报自动以上周入库指标为基准秒级计算环比增长率。
5. **手写模块与反思草稿生成**：
   - 基于超期或异常指标自动生成反思草稿，支持手写补充说明；
   - 支持设备点检、设备保养、必应回复、任务格子、集体培训（含考试分数统计与激励）、嘟嘟卡、系统改进建议（4条）等模块的手动填报。
6. **图表可视化与微信群一键推送**：
   - Recharts 图表展示车间占比饼图、部门打卡条形图、环比 Badge；
   - 规范排版的微信群格式周报文本实时预览与一键复制；
   - 支持企业微信群机器人 Webhook 一键推送到群。

### 明确不做的范围 (Non-goals)
- 暂不开发外部第三方非企微个人微信的 Hook 注入微服务（采用企微 Webhook + 格式化文本一键复制兜底）。
- 暂不重构工牌生成器或 UPH 算法（留待后续独立 Phase）。

## 2. 验收标准 (Acceptance Criteria)

1. **Excel 解析与识别准确率**：针对 `docs/example/` 中的 4 个真实 Excel 样例，解析识别准确率达到 100%，单元测试全部通过。
2. **环比计算与部门归一准确性**：环比公式正确处理增减及零基准边界；“五组”与“智造五部”正确归一聚合，非制造部门完整列出。
3. **企微机器人推送连通**：在配置有效 Webhook 的情况下，一键推送可成功推送到企微群。
4. **代码质量与构建**：所有新增纯函数与 Actions 配齐 Jest 测试；全量 `npm test` 与 `npm run build` 0 错误 0 警告通过。
