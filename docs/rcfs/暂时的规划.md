## 2. 单个事项字段设计（“一件事情”如何细化？）

每个问题事项分为 **4 个维度**，填报时支持结构化录入：

| 维度 | 字段名称 | 推荐选项 / 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **基础信息** | **事项/痛点名称** | 简明扼要的一句话 | `二车间夜班下班未做嘟嘟上线` |
| | **涉及部门** | 智造一部 ~ 九部 / 品质 / 研发等 | `智造二部` |
| **1. 发现问题** | **问题来源** | 巡检发现 / 数据看板异常 / 员工反馈 / 停机超期 | `现场巡检发现` |
| | **问题根因/现状** | 为什么发生，造成了什么阻碍 | `夜班交接急于下班，常忘记在嘟嘟前台做上线操作，导致白班计划混乱` |
| **2. 做出改善** | **数字化/管理措施** | 采取了什么具体手段根治 | `1. 配置转班提醒机器人群自动播报；2. 现场点对点辅导夜班班长` |
| | **解决状态** | ✅ 已彻底闭环 / 🟡 持续巩固中 / 🔴 需跨部门协调 | `✅ 已彻底闭环` |
| **3. 产生收益** | **收益类型** | **工时节省** / **效率提升** / **损失挽回** / **质量防错** / **风险消除** | `质量防错 + 工时节省` |
| | **量化收益指标** | **数值 + 单位**（让老板看到硬核数字） | `避免计划员每天人工核对 30 分钟，夜班漏上线率由 40% 降至 0%` |
| | **收益折算（可选）** | 折算为节省工时（小时/周）或挽回金额（元） | `每周节约工时 2.5 小时` |

## 3. 收益类型的四大“硬核量化公式”（帮老板算清经济与工时账）

1. **工时节约型（人效提升）**：
   - **公式**：`原手工耗时 - 现系统耗时 = 节约工时`
   - **示例**：工牌排版从原 Python 手工拼版（2小时/批）到工作台一键导入打印（5分钟/批），**每周节约 3.8 小时**。
2. **防错/阻断型（质量与风险）**：
   - **公式**：`异常发生率 / 漏检率下降比例`
   - **示例**：综合点检增加扫码校验后，**员工误操作漏检率由 15% 降至 0%**。
3. **响应提速型（周期缩短）**：
   - **公式**：`流转/关卡时长缩短`
   - **示例**：QC 头条督促机制落地后，**超 48 小时滞留单据从 12 条压缩至 2 条，问题关卡平均耗时缩短 58%**。
4. **设备稼动型（减少浪费）**：
   - **公式**：`提前预警减少的非计划停机时长`
   - **示例**：设备点检提前发现五部冲床气压异常，**避免至少 2 小时突发停机损失**。
