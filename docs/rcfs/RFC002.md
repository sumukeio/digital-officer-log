## 一、已锁定决策（MVP）

### 1. 业务目标

对海铭德导出的 **QC 头条**异常，按车间归属后：

1. 导出 **一张分析 Excel**（全厂概览 + 有数据的车间各一 Sheet）  
2. 导出 **一份纯文本**（7 个智造部门分章节；无数据的部门可省略或写明 0 条——见下）  
3. 页面提供 **复制 Prompt**（另按钮；文本文件本身不含完整 Prompt）  
4. 用户将 Prompt/统计带到 **海铭德 AI** 生成「问题—改善—收益」长文；数字官侧第一版 **不自动调 LLM**，也不强制接 headline-brief（第二版再联动）

### 2. 标准汇报单元（7 个，不是 8 个）

- 智造一部、智造二部、智造三部、智造五部、智造七部、智造八部、智造九部  

### 3. 车间归属规则

| 优先级 | 规则 |
| --- | --- |
| 1 | 机台映射表：`设备编号` 精确匹配 → `车间名称` |
| 2 | 纯数字机台：映射表编号带字母前缀且以该数字结尾（如 `6015`→`ZSJ6015`），排除误匹配 |
| 3 | 设备字段含「X部…」→ `normalizeDepartmentName` |
| 4 | **别名表（固化）** 见下表 |
| 5 | 仍无法归属 → 「未归类」（Excel 单独 Sheet；纯文本单独章节） |

**别名表（2026-09-15 确认）**

| 设备编号原文 | 归属 |
| --- | --- |
| `T001` | 智造二部 |
| `喷绘` | 智造七部 |
| `装箱组` / `装箱6组` / `装箱二组` 等无部名前缀的装箱* | **暂** 智造九部（录入不规范；后续靠规范录入） |
| `吸塑组` / `吸塑二组` 等无部名前缀的吸塑* | **暂** 智造九部（同装箱） |
| `八部吸塑组` 等已含部名 | 按文字归对应智造 X 部 |

### 4. 导出形态

**A. 分析 Excel（一张文件）**

- Sheet「全厂概览」：各车间条数、占比、TOP 问题摘要  
- 之后：**仅有数据的车间**各建一 Sheet（明细 + TOP）；本周 0 条的车间 **不建空 Sheet**  
- Sheet「未归类」（若有）：无法归属的行，便于补别名  

**B. 纯文本（一个文件）**

- 按 7 个部门分章节（建议只输出有数据的部门，与 Excel「有数据才建 Sheet」一致）  
- 内容：统计摘要（条数、TOP 问题等），**不含**完整海铭德 Prompt  

**C. Prompt**

- UI **单独「复制 Prompt」**：可选「全厂」或「当前/指定车间」  
- 结构沿用既有硬约束：问题≤3、改善≤4、收益生产/质量/管理各 1 句 + 量化说明行  

### 5. MVP 明确不做（Non-goals）

- ❌ 自动调用 DeepSeek / 海铭德 API  
- ❌ 第一版强制接入 `/headline-brief` 海报与企微推送（第二版）  
- ❌ 把「装箱/吸塑」做成独立汇报单元  
- ❌ 依赖海铭德导出新增「车间」列（导出无法加列）  

### 6. 数据源与周期

- 优先：当周 `/weekly-summary` 已导入的同源 QC 行（避免重复上传；仅「周」模式联动）  
- 兜底：本模块直接上传 QC Excel  
- 机台映射：导入 `机台映射表.xlsx` 进系统（可更新）  
- **周期三模式**（`/qc-workshop` 左上角切换，2026-09-15 确认）：
  - **周**：与周报自然周对齐，可读写周报缓存  
  - **月**：整月 / 月初至今；←→ 切月  
  - **自定义**：起止日期  
- **整表当区间**：上传的 Excel 整表视为当前所选区间数据，**不按开卡时间裁剪**；周期仅影响标签、缓存桶、Prompt/导出文案

## 二、改善措施

**1. 硅胶板管理要从事后更换转向事前预防**

- 建立硅胶板更换台账与寿命预警，记录每块板使用时长、更换原因、对应产线。
- 对新到硅胶板做入库检验，避免因板厚、硬度、尺寸不匹配导致频繁更换。
- 针对“压裂”“回中不到位”等问题，增加安装后的首件确认和回中机构点检，减少重复换板。

**2. 烫印偏印、漏印要固化工艺参数**

- 换板、换花纹后必须做首件确认，确认印刷位置、颜色、深浅合格后再批量生产。
- 将机头压力、料架高度、回中位置等关键参数标准化，减少“反复调试”。
- 对 TJJ 线重点机台建立每日点检表，提前发现偏印、多印趋势。

**3. 机械手和注塑周边要建立点检与备件计划**

- 对机械手 Y 轴同步带、原点、感应器、伺服电机等易损件制定定期点检和更换计划。
- 对 ZSJ 系列流道、热流道、顶针油污实行定期清洗，避免短路、超温、跳闸。
- 对打不满、飞边、开裂等工艺问题，按机台/穴号记录，持续跟踪，避免重复发生。

**4. 换模和停机待料要加强生产协同**

- 换模、换花纹前提前确认模具、硅胶板、半成品配套情况，减少 6T 线停机待料。
- 建立换模作业标准，明确换模后首件确认责任，避免因换模导致连续质量异常。

---

## 三、收益

**1. 直接生产收益**

- 减少硅胶板反复更换和换板调试时间，可提高 TJJ 烫印线开机率。
- 降低偏印、漏印、多印导致的返工挑选成本，提升烫印一次合格率。
- 减少机械手、伺服、流道异常造成的突发停机，保障生产连续性。

**2. 质量收益**

- 通过首件确认和工艺参数固化，可降低烫印不良流入下工序的风险。
- 加强注塑流道、顶针、热流道管理，可减少缺胶、飞边、开裂、油污等质量异常。

**3. 管理收益**

- 异常分类更加清晰，责任人明确，便于车间快速响应和绩效跟踪。
- 从“坏了再修”转向“提前点检、定期维护”，减少重复性故障。
